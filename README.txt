YOUR FREE INTERACTIVE BIRTHDAY WEBSITE ♡

FILES
- index.html: the website structure
- style.css: colours, layout, animations
- script.js: names, flower notes, photo captions, and interactions
- photos/: put your pictures here
- music/: put the song audio file here

QUICK CUSTOMIZATION
1. Open script.js in any text editor.
2. Edit CONFIG.birthdayName (example: "Aarav" or "my love").
3. Edit CONFIG.letter, flowerNotes, letters, and photoCaptions.
4. Add photos named photo1.jpg, photo2.jpg, ... photo12.jpg inside photos/.
   JPG, PNG, or WEBP all work, but if using a different extension, update the
   corresponding path in CONFIG.photoFiles in script.js.
5. Add a legally obtained audio file named Haareya.mp3 inside music/.
   The music button starts playback only after the visitor taps it.

TEST ON YOUR PHONE
You can open index.html on a computer to preview. For the best test, upload to
GitHub Pages and open the published link on your phone. Some phone file browsers
do not run local website scripts properly.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a new repository. Name it birthday-surprise (Public is easiest for
   GitHub Pages on a free account).
3. Upload index.html, style.css, script.js, README.txt, and the photos/ and
   music/ folders (including your own photos/audio if you want them included).
4. In the repository, open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes. GitHub will show your site link in Settings -> Pages.
8. Open that link on your phone and share it.

IMPORTANT PRIVACY NOTE
If the repository is Public, anyone with the link may be able to view the
website files and any photos or audio you upload. Do not upload private or
sensitive photos. GitHub Pages websites are public-facing; the link is not a
password-protected private page.

The site uses Google Fonts when online; system fonts will be used if offline.
